Advanced Shipping Notice (ASN)

Learn how the DESADV message enables automated goods receipt, real-time shipment tracking, and end-to-end delivery transparency.

Overview

What is an ASN?

An Advanced Shipping Notice (ASN) is a structured electronic message a supplier sends to the buyer before or when goods are shipped — containing exactly what is being shipped, when, in what packaging, and how it's being transported. In SAP/EDI terms the ASN is transmitted as a DESADV IDOC (Dispatch Advice).

Without an ASN, the receiving warehouse doesn't know what's coming until the truck arrives. With an ASN, the warehouse pre-plans unloading, assigns dock doors, creates inbound delivery documents in SAP, and can post goods receipt automatically when the shipment is confirmed via barcode scan.

Data Structure

ASN Hierarchy

An ASN is hierarchically structured — each level adds more detail about the physical shipment.

Level 1 — Shipment Header

  • Supplier & buyer info
  • Dispatch date
  • Expected delivery date
  • Waybill / CMR number
  • Carrier
  • Gross & net weight

Level 2 — Delivery / Order Reference

  • PO number or SA reference
  • Delivery note number
  • Line items being shipped

Level 3 — Packaging (Handling Units)

  • Pallet / box / carton details
  • SSCC barcode per HU
  • HU contents (item + qty)
  • Batch numbers

Level 4 — Item Detail

  • Material number
  • Quantity shipped
  • Batch / serial numbers
  • Country of origin

Key Process

Automated GR via ASN

This is JD's flagship ASN capability — eliminating all manual goods receipt entry.

1

Supplier creates ASN in JD portal

Enters shipment data, packaging hierarchy, and SSCC barcodes for each handling unit.

2

JD validates the ASN

Checks: qty matches PO/SA, SSCC format correct, delivery date within tolerance, all required fields populated.

3

DESADV IDOC sent to SAP

JD transmits the validated ASN to SAP, which creates an Inbound Delivery document automatically.

4

Warehouse pre-plans receiving

Staff see incoming shipment, assign dock door, pre-position resources — all before truck arrives.

5

Warehouse scans SSCC barcode

On arrival, scanner reads the SSCC. SAP matches it to the Inbound Delivery — zero manual entry.

6

GR posted automatically

SAP posts the goods receipt (MIGO) against the correct PO/SA line — no human input required.

7

RECADV back to supplier

JD sends a Receiving Advice to the supplier portal confirming what was received — closing the loop.

Terminology

Key ASN Terms

ASN
Advanced Shipping Notice — electronic pre-notification of a shipment sent before or at dispatch.
DESADV
Dispatch Advice — the IDOC/EDIFACT message type for ASN. DESADV = Delivery EXecution Shipping ADVice.
RECADV
Receiving Advice — the response sent back confirming goods were received, closing the delivery loop.
SSCC
Serial Shipping Container Code — 18-digit barcode uniquely identifying each pallet or package. Enables scan-based GR.
Handling Unit (HU)
A physical shipping unit (pallet, box, carton) tracked with an SSCC barcode in SAP and JD.
Inbound Delivery
SAP document automatically created from ASN data, used to plan and execute goods receipt.
GR (Goods Receipt)
SAP transaction (MIGO) confirming goods arrived. Can be fully automated when triggered by SSCC scan.
EWM
Extended Warehouse Management — SAP's advanced WMS. JD ASNs can create EWM inbound deliveries for complex warehouse operations.
Dispatch Date
When goods left the supplier's facility — triggers ASN creation and supplier status update in JD.
Waybill / CMR
Transport document reference (truck/rail). Captured in the ASN header for shipment tracking.
Business Value

Pain Points ASN Solves

⚠ "Warehouse staff waste hours manually posting GR — quantity and reference errors are common"
SSCC-based scan GR triggered by ASN data eliminates manual entry — scan the barcode, GR is posted automatically with zero errors.
⚠ "Trucks arrive unannounced — dock planning is chaotic and receiving takes all day"
ASN gives 24–72 hours advance notice. Warehouse creates inbound delivery, assigns dock door, pre-positions staff before the truck arrives.
⚠ "Disputes about delivered quantities take weeks to resolve — no one has a clear record"
ASN creates an immutable record of what was shipped; RECADV confirms what was received — discrepancies are immediately visible to both parties.
